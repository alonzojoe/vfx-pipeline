This is Celsius. This is Fahrenheit. What's the difference? Celsius measures temperature using degrees based on water's freezing and boiling points. Fahrenheit uses a different temperature scale. Water boils at 100 degrees Celsius, which is 212 Fahrenheit. This is kilometers. This is miles. What's the difference? A kilometer is a metric unit equal to 1,000 meters. A mile is a longer unit of distance equal to about 1.61 kilometers. So a 5K race is about 3.1 miles. Honestly, I always mix these up when I travel. My trick: multiply miles by 1.6 to get kilometers.
